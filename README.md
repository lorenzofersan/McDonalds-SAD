# SAD McDonald's: filas grandes e otimização da operação

Sistema de Apoio à Decisão (SAD) que usa dados para apoiar o processo decisório da operação de uma lanchonete de fast food, tendo o McDonald's como case.

## O desafio

Filas grandes e otimização da operação. A ideia central do projeto é que bons dados só ajudam a decidir quando partem das **perguntas certas**: onde a fila se forma, por que ela se forma e o que pode ser ajustado na operação para reduzi-la.

## O que foi feito

- Uso de uma base de dados pública do Kaggle.
- Definição das perguntas certas sobre filas e operação.
- Consultas em SQL para responder essas perguntas e apoiar a tomada de decisão.

## Ferramentas

- **SQL** para consulta, tratamento e análise dos dados
- **Claude Code** como apoio no desenvolvimento do projeto

## Principais resultados

O projeto mostra como o uso de dados, guiado pelas perguntas certas, ajuda a enfrentar filas grandes e a otimizar a operação.
